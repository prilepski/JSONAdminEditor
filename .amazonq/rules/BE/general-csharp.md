# General C# Coding Rules
## Purpose
To ensure that all generated and updated C# code adheres to our project's coding style, conventions, and best practices.

## Priority
High

## Instructions
-   **Follow C# naming conventions**: Class names should be `PascalCase`, method names should be `PascalCase`, and local variables should be `camelCase`.
-   **Use modern C# features**: Prefer modern language constructs like `using` declarations, record types, and expression-bodied members where appropriate.
-   **Format code correctly**: Always format code to ensure proper indentation and spacing according to standard C# practices.
-   **Add meaningful comments**: Generate XML documentation comments for all public classes and methods. Ensure inline comments explain complex logic but are not used for self-evident code.
-   **Avoid magic strings and numbers**: Replace hardcoded values with named constants or configuration settings.
